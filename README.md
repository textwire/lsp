# Textwire LSP

This is a Go-based LSP implementation for the Textwire templating language.

> [!IMPORTANT]
> The project moved from [codeberg.org/textwire/lsp](https://codeberg.org/textwire/lsp)!

## Installation

```bash
go get codeberg.com/textwire/lsp
```
